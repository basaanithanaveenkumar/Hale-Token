Hale-Token: Data-Center-Scale MoE LLMs on Apple Silicon

A Rust inference engine for M1–M5 Macs. Hot experts stay pinned in unified memory, recent ones live in an LRU, and the rest stream from the SSD in a page-aligned pack, sized by a bandwidth-aware planner.

TL;DR. Qwen3-235B-A22B touches 22B of its 235B parameters per token, so load only those. Tiered expert cache + 16 KiB-aligned SSD pack + q4_0 kernels + a planner that predicts tok/s for any Mac. Logits match transformers (rel. RMS 1.2e-6), and SSD streaming is bit-identical to RAM.

Abstract

Frontier open-weight language models are sparse mixtures of experts, yet standard inference loads every weight, putting them out of reach of laptops. Hale-Token treats a Mac as a three-tier memory system: pinned hot experts and a byte-budgeted O(1) LRU in unified memory, and every expert on the internal NVMe SSD in a page-aligned, fixed-stride pack read with parallel uncached pread.

A closed-form cost model built from the chip's memory bandwidth, core counts, SSD throughput and RAM sizes the tiers and predicts decode speed before download. Routing statistics saved across runs choose what to pin. On a real Mixtral-architecture MoE, logits match Hugging Face transformers with 100% top-1 agreement. On a shared M1 CI VM, decoding runs at 26–34 tok/s resident and 10.3–11.5 tok/s with only 25% of experts cached. The same measurements exposed a pure-LRU thrashing pathology that the planner now avoids.

Highlights

Three-tier expert cache

Pinned (from hale-routing.json) → O(1) byte-budgeted LRU → SSD. All misses are read concurrently, outside locks.

SSD-optimised pack

16 KiB-aligned fixed-stride records with gate|up|down contiguous: O(1) addressing, one pread per miss, and F_NOCACHE.

Planner

hale plan predicts tok/s for any model on any M1–M5 Mac from bandwidth, cores, RAM and SSD speed.

Quantized kernels

q8_0 / q4_0 experts with 8-bit activations and integer dot products (NEON sdot).

Real models

Qwen3-MoE (30B-A3B, 235B-A22B) and Mixtral (8x7B, 8x22B) straight from HF safetensors via zero-copy mmap.

Verified

Float64 litmus tests at every position, bit-identical SSD vs RAM, and a transformers cross-check on a real MoE. CI runs on arm64 macOS.

Quick start

cargo install --git https://github.com/basaanithanaveenkumar/Hale-Token
hale sysinfo
hale plan --preset qwen3-235b
huggingface-cli download Qwen/Qwen3-30B-A3B --local-dir models/Qwen3-30B-A3B
hale convert models/Qwen3-30B-A3B models/Qwen3-30B-A3B-q4 --expert-dtype q4_0
hale run models/Qwen3-30B-A3B-q4 -p "Explain mixture-of-experts in two sentences."
